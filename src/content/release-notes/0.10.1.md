## Handier has its own look

Handier began as a fork of Handy and, until now, still wore Handy's colours. Handy's name, logo and icon belong to the Handy project, which asks forks to use their own, so this release gives Handier an identity of its own: a new icon, a new wordmark, teal in place of the pink, and the name Handier everywhere you see it — the window, the tray and the installed program.

**If you start Handier from a script or a keyboard shortcut** — common on Linux — the program is now called `handier`. Change `handy --toggle-transcription` to `handier --toggle-transcription`, and `pkill -USR2 -x handy` to `pkill -USR2 -x handier`.

## History shows what was pasted

Each entry now shows the text that actually landed in your app, and copying copies that. When the enhancement layer changed your words, **Show what you said** reveals the original with the removed words struck through.

## Linux and Wayland

A Wayland app only receives key presses while it has focus, so Handier's own shortcut stops working once the window is hidden to the tray. The README now explains how to bind a key in your compositor instead, for GNOME, KDE, Sway, Hyprland and Omarchy.
